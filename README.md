# Blog Web App



A simple blog web application built with **Node.js**, **Express.js** and **EJS**.
Users can create, view, edit and delete blog posts through a clean, responsive interface.



## Features



- **Create posts:** write a new post with a title and content
- **View posts:** all posts are shown on the home page, newest first
- **Edit posts:** update the title or content of any post
- **Delete posts:** remove a post (with a confirmation message)
- **Responsive design:** works on desktop and mobile



## Built With



- Node.js
- Express.js
- EJS (templating)
- CSS (Flexbox)



## How to Run



1. Clone the repository
   git clone https://github.com/AmirMo007/blog-app.git
   cd blog-app

2. Start the server
   nodemon ./index.js

3. Open your browser at http://localhost:3000


**Note**
This version does not use a database. Posts are stored in memory, so they are cleared every time the server restarts.
